# Human Resources Analytics Dashboard – Power BI

An interactive, multi-page Power BI report that helps HR managers analyse **recruitment, turnover, satisfaction, performance, department comparisons and future hiring needs**. Built on a synthetic dataset (620 employees, 7,700+ applications, 1,200+ performance reviews, 2,100+ survey responses, 2022–2026) so it can be shared publicly.

> **Status:** this repository contains the full build kit – data, Power Query (M) scripts, DAX measures, data model, theme, page-by-page report specification and insights. The `.pbix` file is created by following `docs/report_design.md` in Power BI Desktop (Windows). Images in `screenshots/` are **matplotlib preview mock-ups** of the layout, not Power BI exports – replace them with real screenshots after you build the report (see "Screenshots" below).

## Business questions answered
| Area | Questions |
|---|---|
| Recruitment | How many applicants, interviews, offers, hires? Success rate? Time to hire? Best source? |
| Turnover | What is the attrition rate? When, where and why do people leave? |
| Satisfaction | What is the score and which factors drive it? Where is it lowest? |
| Performance | How do ratings differ by department, role, experience, education? |
| Forecast | How many hires will be needed in the next 12 months? |
| Departments | How do headcount, payroll, attrition, performance and satisfaction compare? |

## How to build the report (≈ 2–3 hours)
1. `pip install -r requirements.txt` then `python scripts/generate_data.py` (CSV files are already included).
2. Power BI Desktop → **Get data → Text/CSV** or paste the queries from `powerquery/queries.m` (create a `DataFolder` text parameter pointing to `data/raw/`).
3. Build relationships as in `docs/data_model.md`; mark `Calendar` as the date table; make `Employees[TerminationDate]` an **inactive** relationship.
4. Create a `_Measures` table and paste in measures from `dax/measures.dax`.
5. Import `theme/hr_theme.json` (View → Themes → Browse for themes).
6. Create the 8 pages and the two hidden pages (tooltip, drill-through) using `docs/report_design.md`.
7. Sync slicers (Department, Gender, Job Role, Education, Employment Status) across pages; add bookmarks and navigator.
8. Save as `powerbi/HR_Analytics_Dashboard.pbix`, take screenshots into `screenshots/`.

## Publishing to GitHub
```bash
cd hr-analytics-powerbi
git init && git add . && git commit -m "HR Analytics Power BI project"
git branch -M main
git remote add origin https://github.com/<your-username>/hr-analytics-powerbi.git
git push -u origin main
```
Add `*.pbix` to Git LFS if the file exceeds 100 MB (unlikely here).

## Data note
All data is fictional and generated by `scripts/generate_data.py`. It includes deliberate quality issues (duplicates, inconsistent casing, missing salaries) to demonstrate Power Query cleaning.
